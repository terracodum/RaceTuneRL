- **Tuning Agent** — Bayesian Optimization поверх Driving Agent, подбирает сетап.

## Доменные ловушки — проверять всегда

**Termination vs truncation.**
- termination: вылет, разворот — будущего нет, target критика = только награда.
- truncation: таймаут, конец записи, граница сессии — будущее есть, target = r + γ·V(s').
- При truncation в буфер пишется реальное `next_obs`, не наблюдение после сброса.
- В target критика должен идти только `terminated`, не склеенный `done`.
- «Застрял» — любой вариант, но единообразно; зафиксировать в спецификации.

**Награда.**
- Чистая функция от записанных данных: (телеметрия до шага, действие, телеметрия после). Никакого скрытого состояния env, которого нет в логе.
- Один и тот же код для живой среды и для пересчёта по логам. Не делать «похожую копию» для оффлайна.
- `normalizedCarPosition` переходит с ~1 на ~0 на старт-финише — прогресс через линию обрабатывать явно, покрыть тестом.
- Sanity check на человеческих кругах: быстрее круг → больше сумма награды; нет выбросов на старт-финише.

**Данные.**
- Сессия хранится одним непрерывным логом. Круги — разметкой поверх (тик начала/конца, валидность), физически не резать.
- Эпизоды режутся только по реальным разрывам: пит, пауза, сброс, конец сессии.
- Выкинутый кусок из середины = truncation до дыры + новый эпизод после.
- Условия записи (машина, сетап, шины, топливо, погода, частота) — в метаданных сессии; должны совпадать с условиями агента.

**Действия.**
- Логировать реально применённое действие (из телеметрии AC) и, для агента, отправленную команду. Расхождение = баг масштаба, задержки или сглаживания.
- Масштаб человеческих действий должен совпадать с масштабом действий агента в env (проверять по коду, `файл:строка`).
- Действия НЕ интерполировать при пересэмплировании. Частота человеческих данных = частота step агента.

**Старый CSV (`data/lap_2026-05-27_13-23-37.csv`).**
- 25 Гц, ~12.3k строк, только для EDA и анализа зон — не для буфера агента.
- `car_z` уже инвертирован (`-gfx.carCoordinates[2]`), `gear = phys.gear - 1` (0 = нейтраль).
- `steer` нормализован в [-1, 1], `throttle`/`brake` в [0, 1].
- Нет: вектора скорости, угловой скорости, FFB, истории действий.
- ctypes-структура в рекордере неполная. Если расширяешь — порядок и размеры полей строго как в официальной спецификации AC Shared Memory.

## Зафиксированные решения (не пересматривать без запроса)

- Zone reward: границы зон в точках нейтрального руля; baseline фиксированный. Детали — `docs/zone_reward_notes.md`.
